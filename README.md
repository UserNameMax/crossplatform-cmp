# Артефакты курса — трек Compose Multiplatform

Кроссплатформенная разработка, группа ПИН-252т, семестр 01.09 – 26.12.2026.
Здесь лежит то, что отдаётся студентам: шаблоны воркшопов и демо-стенды лекций.

| Что | Где | Когда пригодится |
|---|---|---|
| Шаблон воркшопа **ПЗ1 «Покедекс»** | `workshop/` — подмодуль, отдельный репозиторий [`pokedex-cmp`](https://github.com/UserNameMax/pokedex-cmp) | к 19.09, склонировать **до** пары |
| Демо-стенд лекции **Л1 «UI и состояние»** | `v1/` | к 15.09, разбирается на лекции |

## Клонировать

```bash
git clone --recurse-submodules https://github.com/UserNameMax/crossplatform-cmp.git
```

Уже склонировали без подмодуля — доберите его:

```bash
git submodule update --init
```

**К воркшопу ПЗ1 этот репозиторий не нужен.** Шаблон клонируется напрямую, командой
из его README, и весит на 75 МБ меньше:

```bash
git clone https://github.com/UserNameMax/pokedex-cmp.git && cd pokedex-cmp
git switch -c feature/lab-1_frame w1-start
./gradlew :desktopApp:run
```

## `workshop/` — шаблон ПЗ1

Ветка по умолчанию — **стартовое состояние**, а не готовый ответ. Каждый чекпойнт пары
помечен тегом: `w1-start` → `w1-cp1` … `w1-cp5` → `w1-end`. Отстали на паре — не догоняйте
руками, возьмите ветку от нужного тега. Подробности и таблица приёмки — в
[README шаблона](https://github.com/UserNameMax/pokedex-cmp#readme).

Подмодуль зафиксирован на коммите, а не на ветке: в зонтичном репозитории видно, какое
состояние шаблона было актуальным. Обновить указатель после правок в шаблоне —

```bash
git -C workshop pull && git add workshop && git commit -m "Шаблон ПЗ1: обновлён указатель"
```

## `v1/` — демо-стенд Л1

Девять демо рекомпозиции на четырёх таргетах, разбор — в `v1/SPEC.md`. Запись каждого
демо лежит в `v1/media/` (75 МБ): лекция идёт онлайн, и видео страхует от того, что живой
запуск не заведётся.

```bash
cd v1 && ./gradlew :desktopApp:run
```

## Чего здесь нет

План курса и спецификации воркшопов — с граблями, рисками и разбором того, что пошло не
так на прогоне, — лежат в рабочей папке преподавателя вне git. Студентам они не отдаются
сознательно: сценарий пары до пары читать нечего.
