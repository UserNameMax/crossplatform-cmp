# Метод курса — скилы для Claude Code

Здесь лежит не материал для студентов, а **метод преподавателя**: как устроен курс, как
готовится каждый тип занятия и как веха проверяется на связность перед выдачей.

## Что здесь

| Скил | О чём |
|---|---|
| `crossplatform-course` | Контекст: сетка занятий, вехи, правила курса, ТЗ, адреса в Notion и репозитории |
| `crossplatform-lecture` | Лекция: шкала глубины D0–D3, гвоздь пары, проверка фактуры замером |
| `crossplatform-workshop` | Воркшоп: чекпойнты «делаю X — вижу Y», теги, механика догона |
| `crossplatform-lab` | Лабораторная: критерии приёмки, страница ЛР, асинхронная сдача |
| `crossplatform-milestone` | Сборка вехи целиком: порядок, согласование стеков, сверка, фиксация |

Первый — общий контекст, три следующих — по типу занятия, последний собирает их в одну работу.

## Как подключить

Скилы читаются из `~/.claude/skills/`. Симлинк вместо копии — чтобы правка метода сразу
попадала в репозиторий и не приходилось помнить про две версии:

```bash
for s in crossplatform-course crossplatform-lecture crossplatform-workshop \
         crossplatform-lab crossplatform-milestone; do
  ln -s "$PWD/skills/$s" ~/.claude/skills/$s
done
```

Проверка — вызвать любой из них: `/crossplatform-course`.

## Под какой курс это написано

Кроссплатформенная разработка, две ветки — Compose Multiplatform и Flutter, — которые проходят
одни и те же вехи по очереди и в декабре сравниваются по накопленным замерам. Отсюда всё
остальное в методе: парность занятий, единый контракт критериев, дневник различий.

Под другой курс меняется **только** `crossplatform-course`: сетка, вехи, правила и адреса
живут там, остальные четыре скила на него ссылаются и предметной специфики не содержат.

## Чего в методе нет

Ни одно занятие курса ещё не проведено: первая лекция 15.09.2026. Метод снят с подготовки, а
не с проведения. Всё, что касается темпа, объёма и реакции группы, размечено как «назначено, а
не измерено», и у каждого скила есть раздел, куда это пишется по факту.
