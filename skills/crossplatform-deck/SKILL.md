# Слайды курса кроссплатформенной разработки

Здесь про то, как страница блока в Notion превращается в показываемые слайды
и как правки со слайдов возвращаются обратно в Notion.

**Метод самой сборки — не здесь, а в репозитории слайдов:**
`/Users/Max/Documents/кросплатформа/decks/DECK-GUIDE.md`. Он лежит там
намеренно, а не в скиле: ночная личность работает с `--setting-sources ''`,
скилы ей недоступны, а файл в рабочем каталоге она читает. Дублировать метод
в двух местах нельзя — разойдётся. **Прочитай DECK-GUIDE.md, прежде чем
трогать `index.html`.**

Про сам курс, сетку, вехи и адреса в Notion — [crossplatform-course](../crossplatform-course/SKILL.md).
Про содержание лекции, шкалу глубины и проверку фактуры —
[crossplatform-lecture](../crossplatform-lecture/SKILL.md). Слайды не выдумывают
содержание, они укладывают уже написанный блок.

## Что здесь чем называется

Слово «колода» в курсе значит две разные вещи, и путать их дорого:

- **колода-первоисточник** — страница блока в Notion, уровень глубины лекции
  («Как устроено · CMP»). Так это слово употребляют скилы лекции и вехи;
- **колода-слайды** — папка в `decks/` с `index.html`.

Вторая собирается из первой. **Первая главнее.**

## Порядок работы

1. Прочитать `decks/DECK-GUIDE.md`.
2. Взять первоисточник в Notion целиком, не по кускам.
3. Собрать `index.html`. Один тезис — один слайд.
4. Проверить: сторож → `./render.sh` → PDF глазами.
5. Отдать человеку на ревью. Ревью идёт слайд за слайдом, правок будет много.
6. Применить правки, снова проверить.
7. **Перенести правки в первоисточник** — см. ниже, это отдельный шаг, и его
   легко забыть.
8. Закоммитить.

## Ревью: чего ждать

Правки повторяются от колоды к колоде. Их стоит внести заранее, а не ждать,
пока человек их назовёт в пятый раз:

- вопросы блока — **вторым слайдом**, финальный слайд «Вопросы» — последним;
- сценарные формулировки со слайда снимаются в заметки;
- «это когда» и прочая разговорная речь заменяется определением через род
  и видовое отличие;
- чужой стек из своей колоды убирается, включая колонки сравнительных таблиц;
- где просят «закопаться» — добавляется код, а не ещё один абзац прозы;
- два слайда, отвечающие на один вопрос, сводятся в один.

Полный список с примерами — в `DECK-GUIDE.md`, раздел 4.

## Обратный перенос в Notion

Правка, сделанная на слайде, **обязана** доехать до страницы блока: иначе
через месяц это две версии курса. Порядок:

1. Свежий `notion-fetch` страницы прямо перед правкой — не по памяти.
2. Готовить точечные замены, а не переписывать страницу.
3. Проверить результат вторым `notion-fetch`.

Грабли, каждая из которых уже случилась:

- **`update_content` атомарен.** Одна строка не совпала — не применилось
  ничего. Совпадение должно быть побуквенным: «прочтётся» вместо «прочитается»
  роняет весь батч. Опорный фрагмент брать копированием из `fetch`, не набирать.
- **Не удалять половину `callout`.** Если снести тело блока вместе с
  закрывающим тегом, но оставить открывающий, следующие разделы страницы
  втянутся внутрь callout. Удаляется только целый сбалансированный блок.
- **Переименование select-опции пересоздаёт опцию и молча обнуляет строки.**
  Безопасно только так: ДОБАВИТЬ новую опцию → переназначить строки →
  проверить через `GROUP BY` → УДАЛИТЬ старую.
- Порядок разделов на странице держать тем же, что порядок слайдов.

Ночью этот шаг не делается: у ночной личности нет авторизации коннектора.

## Ночная сборка

Ночь умеет собирать колоды по готовому первоисточнику. Ограничения — в
`DECK-GUIDE.md`, раздел 9; главное: из проверки ей доступен только
`python3 check-decks.py`, рендера и глаз у неё нет.

Проект в реестре ночи называется `kross-decks`. Задача ставится через скил
[night-task](~/.claude/skills/night-task/SKILL.md):

```bash
HUB="/Users/Max/Documents/Default Project/night-personality"
"$HUB/bin/task.sh" add "собрать колоду Л1 «Как устроено · состояние»" \
  -p kross-decks \
  -c "python3 check-decks.py — l1-ustroystvo зелёный, без «⚠ плотно»; второй слайд «Вопросы блока», последний «Вопросы»; у каждого слайда непустая заметка" \
  -x "первоисточник — страница Notion <url>; метод и ограничения ночи — DECK-GUIDE.md в корне репозитория"
```

Одна ночная задача — **одна колода**. Утром колода разбирается ревью по
пунктам выше: ночь укладывает материал, отделку делает человек.
