# Демо-стенд Л4

Артефакты к лекции **Л4 «Данные и асинхронность» (CMP)** курса кроссплатформенной
разработки, веха В2. 27.10, онлайн, Compose Multiplatform.

Движок стенда (навигация, тема, реестр демо) скопирован из `artifacts/v1` — стенд заводится
один на веху, а не на весь курс (решено 24.08.2026).

- Спецификация артефактов — [SPEC.md](SPEC.md)
- Конспекты лекции — в Notion, «Материалы курса → Занятия → Л4»
- Правила демо и приёмки — скил `crossplatform-lecture`, `references/artifacts.md`

## Запуск

```bash
./gradlew :androidApp:assembleDebug
./gradlew :desktopApp:run
./gradlew :webApp:wasmJsBrowserDevelopmentRun
```

iOS — открыть `iosApp/iosApp.xcodeproj` в Xcode и запустить; Gradle-фаза внутри проекта
соберёт фреймворк сама.

Стенд собран и проверен на **четырёх таргетах**: Android (`assembleDebug`), JVM desktop
(компиляция), web/wasmJs (живой прогон в браузере), iOS arm64 + симулятор (компиляция).
Обязательные для курса — первые три; iOS у студентов идёт бонусом.

## Демо

Семь демо по уровням шкалы глубины. Порядок в списке стенда = порядок показа на паре.

| Уровень | Демо | Что показывает |
|---|---|---|
| Как пользоваться | DTO -> domain -> UI | переименование поля на сервере правится только в mapper |
| | Состояние экрана | sealed-сумма не допускает невозможных комбинаций, три флажка — допускают |
| | Пагинация | дозагрузка по живым данным PokéAPI, без дублей и лишних запросов |
| | Дебаунс | надстройка над поиском: 3 изменения текста → 1 запрос вместо 3 |
| Как устроено | Flow: cold vs hot | cold-подписчик = новый запрос, StateFlow = один на всех; conflation — эмиттер не ждёт медленного подписчика |
| | Сериализация | дескриптор из кодогенерации; без `@Serializable` — настоящий `SerializationException` в рантайме |
| Под капотом | Уход во время загрузки | **гвоздь пары**: `GlobalScope` — утечка в мёртвый экран, `viewModelScope` — чисто |

Каждое демо со состоянием «сломано / починено» переключается тумблером или кнопкой в самом
приложении. Пересборка на живой онлайн-паре недопустима.

## Структура

| Путь | Что |
|---|---|
| `shared/src/commonMain/kotlin/.../stand/` | оболочка и служебные инструменты. **Студентам с экрана не показывается** |
| `shared/src/commonMain/kotlin/.../demo/d1\|d2\|d3/` | сами демо по уровням глубины |
| `shared/src/commonMain/kotlin/.../data/pokeapi/` | Ktor-клиент и DTO живых данных PokéAPI |
| `shared/src/commonMain/kotlin/.../domain/ScreenState.kt` | sealed-состояние экрана, общее для A3 и C1 |
| `shared/src/commonTest/kotlin/.../verify/` | проверка гвоздя замером — `StructuredConcurrencyVerification.kt` |
| `shared/src/commonMain/composeResources/` | подписи интерфейса, локали `values` и `values-en` |

**Строк в коде нет.** Курс требует этого от студентов с первой вехи, стенд следует тому же
правилу — все подписи всех семи демо в ресурсах, проверено `grep` по исходникам на кириллицу.
