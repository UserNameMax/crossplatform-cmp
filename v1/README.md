# Демо-стенд Л1

Артефакты к лекции **Л1 «UI и состояние»** курса кроссплатформенной разработки.
15.09, онлайн, Compose Multiplatform.

Лекция построена так, что показывается не слайд, а работающее демо: правило курса
требует артефакта у самого глубокого блока, а онлайн-формат не прощает разговора
без картинки на экране.

- Спецификация артефактов — [SPEC.md](SPEC.md)
- Конспекты лекции — в Notion, «Материалы курса → Занятия → Л1»

## Запуск

```bash
./gradlew :androidApp:assembleDebug
./gradlew :desktopApp:run
./gradlew :webApp:wasmJsBrowserDevelopmentRun
```

iOS — открыть `iosApp/iosApp.xcodeproj` в Xcode и запустить; Gradle-фаза внутри проекта
соберёт фреймворк сама. Для устройства нужно вписать `TEAM_ID` в
[Config.xcconfig](iosApp/Configuration/Config.xcconfig), для симулятора не нужно.

Стенд собран и проверен на **четырёх таргетах**: Android, web (wasmJs), JVM desktop, iOS.
Обязательные для курса — первые три; iOS у студентов идёт бонусом, без macOS его не собрать.

## Демо

Пятнадцать демо, сгруппированных по уровням шкалы глубины курса. Порядок в списке — порядок
показа на паре, внутри уровня он совпадает с порядком слайдов колоды.

| Уровень | Демо | Что показывает | Слайд колоды |
|---|---|---|---|
| Как пользоваться | remember и ввод | без `remember` поле не принимает ввод | D1 «remember» |
| | Подъём состояния | состояние во ViewModel, поле без состояния в двух местах; с `remember` внутри ViewModel о поле не знает | D1 «Подъём состояния», «Зачем поднимать» |
| | Тема и захардкоженный цвет | цвет мимо токенов не переключается; поддерево со своей темой | D1 «Тема в коде», «Тема: где ломается» |
| | Модель в маршруте | в маршруте id — экран свежий, модель целиком — копия устарела | D1 «Навигация: где ломается» |
| Как устроено | Рекомпозиция и переизмерение | набор буквы — композиция, сужение окна — только layout и отрисовка | D2 «Разные вещи» |
| | Учебная колонка | код со слайда против настоящего `Column` в рамке с `fillMaxSize()` | D2 «Три шага в коде», «Где учебная колонка проще» |
| | Модификаторы по фазам | `offset(y = …)` против `offset { … }`: счётчик композиции | D2 «Модификаторы по фазам» |
| | Порядок модификаторов | четыре цепочки, размеры сняты с узла | D2 «Порядок модификаторов» |
| | Один проход измерения | интринсики не измеряют детей дважды | D2 «Интринсики» |
| | Бесконечная высота | прокручиваемое внутри прокручиваемого падает, настоящий текст исключения | D2 «Где ломается» |
| Под капотом | Память по позиции вызова | два вызова одной функции — две памяти; уход с ветки выбрасывает слоты | D3 «Slot table», «Демо: две ветки» |
| | Чтение и запись состояния | перезапускается тот, кто прочитал; запись равного не будит никого | D3 «State изнутри» |
| | Ключи в списке | без ключа локальное состояние уезжает при вставке | D3 «Зачем ключ в списке» |
| | Поиск и лишние перерисовки | **гвоздь пары**: чем именно вас сравнивают | D3 «Рекомпозиция на дереве», «Что ломает пропуск» |
| | Три способа починить | посчитать выше, `remember` с ключом, `@Stable` | D3 «Три способа починить» |

Каждое демо со состоянием «сломано / починено» переключается тумблером в самом приложении.
Пересборка на живой онлайн-паре недопустима: это полторы минуты тишины.

Стенд сам иллюстрирует D1: навигация — Navigation 3 со стеком из объектов-экранов, как на слайдах
и в шаблоне ПЗ1; тема — токены из `StandTheme`, стартует от системной настройки.

## Структура

| Путь | Что |
|---|---|
| `shared/src/commonMain/kotlin/.../stand/` | оболочка и служебные инструменты. **Студентам с экрана не показывается** |
| `shared/src/commonMain/kotlin/.../demo/d1|d2|d3/` | сами демо по уровням глубины |
| `shared/src/commonMain/kotlin/.../data/DemoItems.kt` | единственное место с предметными данными — покемоны, как в шаблоне ПЗ1 |
| `shared/src/commonMain/composeResources/` | все подписи интерфейса, локали `values` и `values-en` |
| `media/` | съёмка демо по платформам |

Граница `stand/` и `demo/` — не косметика. Код из `demo/` показывается с экрана, поэтому
в нём нет конструкций, которые на Л1 ещё не объяснены. Механика счётчиков живёт в `stand/`.

**Строк в коде нет.** Курс требует этого от студентов с первой вехи, поэтому стенд следует
тому же правилу: 144 ключа в двух локалях. Исключения помечены комментариями — дословный
текст исключения в демо про бесконечную высоту, листинги кода на экране и имена покемонов.

## Съёмка

`media/android`, `media/ios`, `media/jvm` — по восемь файлов на платформу: семь видео и
статичный `modifier order.png`. Демо про бесконечную высоту не снималось: оно роняет
приложение, для того и сделано.

Съёмка сделана до 14.09.2026: шести демо, добавленных по сверке с колодами, в ней нет, а
«Подъём состояния», «Тему» и «Порядок модификаторов» с тех пор переделали.

## Отчёты компилятора

Включены в `shared/build.gradle.kts`, после сборки лежат в `shared/build/compose_compiler/`.

Нужны дважды. Ими проверялось поведение демо про перерисовки — и они опровергли два
утверждения, которые сначала попали в конспект (подробности в [SPEC.md](SPEC.md), раздел
«Что выяснилось при реализации»). И они же идут артефактом на **ПЗ7 12.12**, где студенты
открывают такой отчёт на своём коде.
