# Страховка к паре

Снимки сделаны `./gradlew :desktopApp:renderCheck` — тем же кодом, что идёт на пару,
без окна и без записи экрана. Если на паре что-то не поедет, показываются они.

`adaptive-480.png` и `adaptive.png` — одно демо на двух ширинах: это и есть приёмка
адаптива, «делаю X — вижу Y» в двух картинках.

**Видео здесь нет сознательно.** Съёмку делает преподаватель, а не скил; до неё стенд
доведён до состояния «можно снимать». Чеклист съёмки — в SPEC.md. Плюс по медиа в истории
не закрыт открытый вопрос (`v1/media` весит 75 МБ), и до его решения тяжёлое сюда не кладём.
